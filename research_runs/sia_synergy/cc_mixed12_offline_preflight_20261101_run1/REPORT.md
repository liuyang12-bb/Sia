# 12 作业混合场景：FO/FULL 离线机会预检

**SYNTHETIC CROSS-HARDWARE TRANSFER — NOT REAL SATURN PERFORMANCE**

## 1. 结论与本轮边界

结论：**候选覆盖、物理容量和条件性联合选择机会通过；值得开展这个冻结的 12 作业小型 FO/FULL 验证，但真实在线持续性仍未验收。** 不将它称为已经保证 FULL 大幅降低 JCT 的场景。下一步若获授权，应先检查短前缀的真实事件选择和后续执行，满足预注册机会条件后再读完整 JCT；本轮到此停止。

最直接的机会是 GPU 与辅助资源被分隔：在同一参考状态下，真实 FO 已优化 CPU/RAM，但 AWS 的 4 张 GPU 被 BERT 占用、14 个 CPU 单位闲置；RTX 的 CPU 几乎用满，CIFAR 仍争用 CPU。FULL 改变 BERT/CIFAR/DeepSpeech2 的 GPU 配置，将闲置的 AWS CPU 用于 CIFAR。这个机会不是“FO 没有做辅助资源优化”。

反面证据也保留：FULL 会牺牲 DeepSpeech2 的速度，恒定配置 ETA 总和变差。参考模型下的净进度优势不是净 JCT 优势；需要实际完成后的资源释放补偿受损作业。BERT 在当前模板中完全不敏感，不能冒称内存敏感任务。

本轮没有调用 Job.step 或 Cluster.step，没有训练推进、完成事件或 JCT。只进行了全域候选枚举、6 次小型静态 MIP、4 次真实控制器的单次 optimize_policy 调用及 8 项离线核对。所有调用在独立诊断进程中进行；不修改调度源码或正式初始化。

## 4. 数据域、边界与候选覆盖

全部 12×6=72 作业/GPU 配置对有 R0 和正的离线参考预测率，缺失 0；每个配置比例点物理可行。计入重复作业后的候选记录 59060 条，其中分子裁剪 7392（12.52%），分母裁剪 2838（4.81%），分子与分母都受支持 49364（83.58%）。两类裁剪可重叠，不相加当作总越界率；这是候选级计数，不是运行时间加权裁剪率。

分母越界只涉及两个 BERT 的 RTX:1:1：3/phi_c≈0.99155<1；比例点分子同样越界。BERT 矩阵恒为 1，数值结果仍为 rho=1，但仍记录越界。CIFAR/DeepSpeech2 的六种 GPU 配置参考分母均在域内。低资源候选仍大量分子越界，不得将 clipped donor 宣称为实测的无损让出方。

两波在本离线参考模型中的应用、合法配置、phi、模板、剩余工作与预测率逐项相等，核验后复用同一六任务静态求解。没有把第二波算成独立实验重复，也没有模拟第二波的真实在线状态。

## 5. 同状态 FO/FULL：真实调度入口的单次选择

## 6. 持续性预检：条件通过，实际执行尚待验证

预注册了两个参考状态 E0、E25。E25 使用 floor(0.25×max_epochs)：CIFAR epoch25、DeepSpeech2 epoch20、BERT epoch0（BERT 总共2 epoch）。它们不是从一次运行连续采样的两个时刻，不能把它们之间称为实际持续收益。

对同一固定六任务服务集合，FO 先用比例点选 GPU，再固定 GPU 优化 CPU/RAM；FULL 联合求解。使用相同节点约束、已存在候选、当前算法主目标。每个静态 MIP 均 status=0、gap=0，独立容量核对通过；只复现主资源子问题，不宣称复现控制器的 FIFO、历史锁、恢复预算和全部并列解规则。
